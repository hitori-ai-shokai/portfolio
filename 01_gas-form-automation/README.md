# フォーム回答 自動処理ツール(Google Apps Script)

Googleフォームで受け付けた問い合わせを、**転記・担当の振り分け・自動返信・チャット通知・毎朝のサマリー**まで自動化するツールです。
設定はすべてスプレッドシートの「設定」シートで変更でき、コードを触る必要はありません。

## できること
| 機能 | 内容 |
|---|---|
| 自動転記 | 回答を「管理」シートに、受付番号(例:20261016-001)・担当者・ステータス・対応期限を付けて記録 |
| 担当の振り分け | 「担当振り分け」シートで、種別ごとに担当者を自動で割り当て |
| 自動返信 | 回答者へ、受付番号と対応期限を入れたメールを送信(文面は設定シートで編集) |
| チャット通知 | Slack・Google Chat の Webhook URL を設定すると、新着をすぐ通知 |
| 毎朝のサマリー | 担当者別の未対応件数と、期限切れの一覧を毎朝8時にメールで送信 |
| 営業日計算 | 対応期限は土日を除いた営業日で計算 |

## 導入手順(約10分)
1. フォームの回答先スプレッドシートを開き、「拡張機能 > Apps Script」を開く
2. `Code.gs` の内容をすべて貼り付けて保存する
3. 関数 `setup` を選んで「実行」を押し、権限を許可する
   → 「設定」「担当振り分け」「管理」シートと、トリガー2つが自動で作られる
4. 「設定」シートの「列名:〜」を、お使いのフォームの質問名に合わせる
5. 必要に応じて、返信文・通知先・サマリーの送信先を書き換える

## 設計上の工夫
- **フォームの質問名が違っても動く**:列名の対応を設定シートで持っている
- **同時送信でも受付番号が重複しない**:`LockService` で排他制御している
- **通知が失敗しても、転記と返信は止まらない**:外部サービスの障害を切り離している
- **ロジックを単体テスト済み**:シート操作と処理ロジックを分けているため、Node.js でテストできる(`node test/run_test.js`)

## 応用例
問い合わせ管理、予約受付、社内の申請・稟議、イベント申込、採用の応募受付など
