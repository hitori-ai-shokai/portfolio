# 月次売上レポート 自動作成ツール(Python)

店舗ごと・ECモールごとに**形式がバラバラな売上ファイル(CSV・Excel)**をまとめて読み込み、
グラフ付きの**月次レポート(Excel)**を1コマンドで作ります。

```
python report_builder.py --input sample_data --month 2026-09
```
```
読み込み: 3ファイル / 340行(エラー 2行)
2026-09 の売上合計: ¥598,220(154件)
前月比: -19.7%
出力: output\report_2026-09.xlsx
```

## 解決すること
「毎月、楽天・Amazon・実店舗のデータをコピペして、Excelで集計し直している」という作業をなくします。

## 吸収できる「ゆれ」
| ゆれ | 例 | 対応 |
|---|---|---|
| 文字コード | Shift_JIS / UTF-8 / UTF-8(BOM付き) | 自動で判別 |
| 列名 | 「注文日」「売上日」「order_date」 | `config.json` で対応づけ(コード修正は不要) |
| 先頭の説明行 | 「# 注文レポート」などの行 | ヘッダー行を自動で探す |
| 金額の表記 | 「￥1,280」「1,280円」「1280」(全角) | 数値に変換 |
| 金額の列がない | 単価と数量しかない | 単価 × 数量で計算 |
| 日付の表記 | 2026/9/1、2026-09-01、20260901、2026年9月1日、Excelの日付 | すべて日付に変換 |
| チャネル列がない | ファイルごとにモールが違う | ファイル名から判定(例:rakuten → 楽天市場) |

## 出力されるレポート(Excel・6シート)
1. **サマリー**:売上合計、取引件数、平均単価、前月比、読み込めなかった行の数
2. **日別推移**:日ごとの売上と折れ線グラフ(売上がない日も0として表示)
3. **チャネル別**:売上・件数・構成比と棒グラフ
4. **商品ランキング**:売上の上位N商品(Nは設定で変更できる)
5. **明細**:全ファイルを統合した明細(フィルター付き)
6. **エラー行**:読めなかった行を、**ファイル名・行番号・理由つき**で一覧にする(データを黙って捨てない)

## 使い方
```
pip install -r requirements.txt
python make_sample_data.py          # デモ用のサンプルデータを作る
python report_builder.py --input sample_data --month 2026-09
python -m unittest discover -s tests  # テスト(6件)
```

## 応用例(受託で対応できること)
- 毎月1日に自動実行し、レポートをメールやSlackで送る
- Googleスプレッドシート・Googleドライブへの自動アップロード
- 在庫データ・広告費データと組み合わせた利益レポート
- 社内の別システムのCSV(会計ソフト、POSレジ)への対応
