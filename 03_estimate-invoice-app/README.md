# 見積書・請求書メーカー(Webアプリ)

ブラウザだけで動く、見積書・請求書・納品書の作成アプリです。インストールもサーバーも不要で、HTMLファイル1つで動きます。

## できること
- 見積書・請求書・納品書の切り替え(書類番号を自動採番:Q-202610-001 など)
- **インボイス制度に対応**:登録番号の記載、税率ごと(10%・8%)の合計と消費税額、軽減税率の※印
- **消費税の端数処理は税率ごとに1回だけ**(切り捨て・四捨五入・切り上げを選択可能)
- A4レイアウトでプレビューし、そのままPDF保存・印刷
- 書類の保存・複製・削除(ブラウザ内に保存。外部に送信しない)
- JSONでのバックアップ・復元、書類一覧のCSV出力(Excelで開いても文字化けしないBOM付き)
- スマホ表示に対応

## 使い方
1. `index.html` をブラウザで開く(または GitHub Pages で公開したURLを開く)
2. 「自社情報」に会社名・住所・登録番号を入れる(次回から自動で入る)
3. 宛先・件名・明細を入力すると、右側のプレビューに即時反映される
4. 「PDFで保存・印刷」→ 印刷ダイアログで「PDFに保存」を選ぶ

## カスタマイズの例(受託で対応できること)
- 自社ロゴ・印影の画像を入れる
- 顧客マスタ・品目マスタからの選択入力
- Googleスプレッドシートやkintoneとの連携(書類データの自動保存)
- 源泉徴収税の計算、複数通貨への対応
